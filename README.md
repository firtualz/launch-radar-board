Token Radar ranks every clean pre-token protocol by what its launch would be worth, fitted from the protocols that already trade, with a costed farm plan and a farm/thin/skip verdict for each row. It reads a sealed DefiLlama snapshot and writes a ranked board, a static dashboard and a dossier.

## Run it

```sh
node main.ts
```
